Gov.Pass 🏅

Democratizando o acesso ao esporte e promovendo qualidade de vida para todos.

O Gov.Pass é uma plataforma desenvolvida com o propósito de democratizar o acesso às atividades esportivas disponibilizadas por programas do governo brasileiro.

A proposta é centralizar e facilitar a consulta de vagas em diferentes modalidades esportivas, permitindo que qualquer pessoa encontre oportunidades próximas de sua região e tenha mais facilidade para iniciar ou continuar a prática de atividades físicas.

Acreditamos que o esporte deve ser acessível a todos, independentemente da condição social ou experiência. Mais do que incentivar a prática esportiva, o Gov.Pass busca contribuir para a saúde física, o bem-estar mental, a inclusão social e a qualidade de vida da população.

🎯 Objetivo do Projeto

O principal objetivo do Gov.Pass é facilitar o acesso da população às vagas esportivas oferecidas pelo governo, reunindo informações sobre modalidades, locais de prática e oportunidades disponíveis.

A plataforma busca solucionar uma dificuldade comum: muitas pessoas não conhecem os programas esportivos disponíveis em suas cidades ou encontram dificuldades para localizar informações sobre inscrições, horários e disponibilidade de vagas.

Com isso, o Gov.Pass pretende:

Democratizar o acesso ao esporte.

Facilitar a localização de atividades esportivas gratuitas ou disponibilizadas por programas públicos.

Centralizar informações sobre modalidades esportivas.

Aproximar a população das iniciativas esportivas governamentais.

Incentivar hábitos saudáveis e a prática regular de exercícios.

Contribuir para a saúde física e mental.

Promover inclusão social por meio do esporte.

💡 Problema e Solução

Problema

A falta de centralização das informações sobre programas esportivos governamentais dificulta o acesso da população às oportunidades disponíveis. Muitas pessoas deixam de praticar esportes por desconhecerem os projetos existentes ou não saberem onde encontrar vagas.

Solução

O Gov.Pass propõe uma plataforma digital que facilita a visualização e a busca por oportunidades esportivas, utilizando recursos tecnológicos para tornar a experiência mais simples, acessível e intuitiva.

📋 Pré-requisitos

Antes de iniciar a aplicação, certifique-se de possuir:

Node.js instalado (versão compatível com Vite 8).

npm para gerenciamento de dependências.

Git instalado.

Editor de código de sua preferência (recomendado: Visual Studio Code).

🚀 Como executar o projeto

1. Clonar o repositório

Abra o terminal e execute:

git clone https://github.com/theodoleo99/Gov.Pass.git

Entre na pasta do projeto:

cd Gov.Pass

2. Instalar as dependências

npm install

3. Executar a aplicação

Para iniciar o ambiente de desenvolvimento:

npm run dev

Após iniciar o servidor, acesse:

http://localhost:3000

Principais diretórios e arquivos

public/: armazena arquivos estáticos disponibilizados pela aplicação.

public/assets/: reúne recursos visuais e outros arquivos utilizados pelo projeto.

src/: diretório principal do código-fonte, onde ficam os componentes e funcionalidades da aplicação.

.env.example: modelo das variáveis de ambiente necessárias para configuração.

package.json: contém as dependências, informações e scripts de execução.

bun.lock: arquivo de controle das versões das dependências instaladas pelo Bun.

tsconfig.json: configura o compilador e as regras do TypeScript.

vite.config.ts: configura o ambiente de desenvolvimento e compilação utilizando Vite.

index.html: documento HTML inicial da aplicação.

metadata.json: arquivo de metadados do projeto.
